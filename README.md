Program ini dibuat untuk membantu mengatur peminjaman buku di perpustakaan. Di dalam program ada daftar buku yang tersediaa lalu kita bisa memilih meny untuk meminjam atau menghapus buku yang sudah dipinjam.
daftar buku digunakan tuple karena daftar bukunnya tetap. Sedangkan buku yng dipinjam menggunakan list karena isinya bisa bertambah atau berkurang.

input() digunakan supaya kita bisa mamasukkan pilihan atau judul buku. if, elif, dan else digunakan untuk menentukan menu yang dipilih. for digunakan untuk menampilkan buku satu per satu. Sedangkan remove() digunakan untuk menghapus buku dari daftar pinjaman.
